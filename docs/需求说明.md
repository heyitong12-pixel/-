# 文件库页面需求说明

## 1. 项目概述

文件库管理页面原型，用于展示文件资料的分类管理、检索与视图展示能力，覆盖技术文档、产品资料、售后资料等场景。

## 2. 功能需求

### 2.1 分类导航（侧边栏）

- 两级分类结构：`Technical Support`、`After-sales Service`、`Product Information` 为一级分类；
- 一级分类下可展开子分类（如 `Cloud Platform`、`Gateway`、`ESL`、`APP`、`MQTT`、`Deployment`）；
- 支持选中态高亮，默认选中 `MQTT`。

### 2.2 文件检索

- 顶部提供搜索框，按名称关键字检索文件；
- 支持排序（按修改时间、名称、大小、类型）。

### 2.3 视图切换

- 提供「卡片视图」与「列表视图」两种展示方式，一键切换；
- 卡片视图：文件图标 + 文件名，网格布局；
- 列表视图：表格展示，列包含复选框、文件名、类型、大小、修改时间、上传人、操作。

### 2.4 文件操作

- 列表视图操作列提供：预览、下载、分享（压缩包仅有下载、分享）。

### 2.5 分页

- 展示记录总数与当前页码；
- 支持页码切换、每页条数（12/20/50 条）切换、跳转到指定页。

## 3. 跳转测试页

用于验证多页面原型间的跳转与导航：

| 页面 | 说明 |
|------|------|
| `page1.html` | 数据表格：设备运行状态列表 |
| `page2.html` | 卡片列表：文档卡片展示 |
| `page3.html` | 表单交互：表单提交本地提示 |

各测试页提供统一顶部导航（首页/表格/卡片/表单），当前页高亮，可互相跳转并返回首页。

## 4. 非功能要求

- 纯静态单文件页面，无外部依赖，所有样式与脚本内联；
- 页面间使用相对路径链接跳转，保证本地 `file://` 与线上部署均可正常访问。
