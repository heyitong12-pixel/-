# ESL 智能标签 APP · 首页交互文档（供开发实现）

> 文档版本：v1.0　适用原型：`esl-app.html`（首页 = 我的空间）
> 面向对象：前端/客户端开发、UI 开发
> 说明：本文档描述「我的空间」首页的所有界面元素、交互逻辑、状态与数据来源，开发可据此实现，无需再逐一对照原型询问。

---

## 1. 页面定位与信息架构

「我的空间」是 APP 的**默认首页**，承载「当前所在空间概览 + 高频操作入口」两大职责。

### 页面结构（自上而下）

```
┌────────────────────────────────┐
│ 顶栏 Topbar                    │
│  ├ 标题：ESL 智能标签（品牌弱化）│
│  └ 右侧：📷 扫码（胶囊按钮）     │
├────────────────────────────────┤
│ 空间栏 StoreBar                │
│  ├ 图标 🏬 + 空间名（大标题）    │
│  ├ 副信息：设备数量统计         │
│  └ 右侧：切换箭头（圆形）       │
├────────────────────────────────┤
│ 设备概览 OverviewBar（可点击）   │
│  └ 3 列：网关 / ESL标签 / LCD屏 │
├────────────────────────────────┤
│ 待办提示条 TodoBar（有异常才显示）│
├────────────────────────────────┤
│ 金刚区 Quick                   │
│  ├ 主按钮区 HeroRow（2个并排）  │
│  │   ├ 绑定标签                 │
│  │   └ LCD绑定                  │
│  ├ 常用功能（4个图标）           │
│  └ 更多工具（3个弱化图标）       │
└────────────────────────────────┘
```

## 2. 各区域详细说明

### 2.1 顶栏 Topbar

| 项 | 说明 |
|----|------|
| 布局 | 渐变背景（#5b7cfa → #6a5bfa），白色文字 |
| 左标题 | 「ESL 智能标签」，13px，半透明弱化，仅作品牌标识 |
| 右按钮 | 「📷 扫码」，胶囊样式（圆角16px，白底20%透明度） |
| 交互 | 点击「扫码」→ 弹出扫码弹窗（见 §3.3） |
| 常驻 | 首页常驻；切换页面时标题需替换为对应页面名（见 §5） |

### 2.2 空间栏 StoreBar

| 项 | 说明 |
|----|------|
| 空间图标 | 🏬（46px，圆角12px，白色20%透明底） |
| 空间名 | 「XX 连锁 · 一号店」，20px 加粗，页面视觉主角 |
| 副信息 | 「3 个网关 · 11 个 ESL · 5 个 LCD」，11px，半透明 |
| 切换箭头 | 右侧圆形白色20%透明底 + ▾ 箭头 |
| 交互 | 点击整栏 → 弹出「空间切换」底部弹层（见 §3.2） |

### 2.3 设备概览 OverviewBar

| 项 | 说明 |
|----|------|
| 结构 | 白色卡片内 3 列均分，列间细分隔线 |
| 3 列 | ①网关 ②ESL 标签 ③LCD 屏，每列含「名称 + 在线/离线数 + 查看 ›」 |
| 状态色 | 在线=绿 #2ec47b，离线=灰 #9aa3b5，告警=橙 #e6a23c |
| 交互 | **点击整列 → 跳转对应设备列表页**（当前原型统一跳「标签」页） |
| 数据 | 在线/离线数量来自设备接口实时统计（见 §4） |

**展示规则**：
- 每列始终展示「在线数 + 离线数」两个数字。
- 离线数 > 0 时该数字用「告警色」（橙），否则用「灰色」。

### 2.4 待办提示条 TodoBar

| 项 | 说明 |
|----|------|
| 位置 | 设备概览下方，与概览之间留 10px 间距 |
| 样式 | 白底卡片，左侧 4px 橙色边条，🔔 图标 |
| 文案 | 「有 **1** 台 ESL 离线、**1** 台 LCD 待处理」；数字用红色 #e0574b 加粗 |

| 交互 | 点击 → 跳转标签/待处理列表页 |
| **显隐规则** | **有任意离线/告警/待处理项时显示；全部正常时隐藏整条** |

### 2.5 金刚区 Quick

**主按钮区 HeroRow（2 个同级并排）**

| 按钮 | 图标 | 主文案 | 副文案 | 点击 |

## 3. 交互流程

### 3.1 扫码入口（两处）
1. 顶栏「📷 扫码」按钮
2. 金刚区「绑定标签」/「LCD绑定」主按钮

均触发同一个**扫码弹窗**。

### 3.2 空间切换流程
1. 点击空间栏（整栏可点）→ 底部弹出「切换门店/空间」弹层
2. 弹层列出当前账号下所有空间（含图标、名称、设备数量）
3. 点击某一空间 → 选中并更新：
   - 空间名（s-name）
   - 设备数量副信息（s-meta）
   - 当前空间标记 ✓
4. 切换后**设备概览、待办提示、金刚区数据全部刷新**为该空间数据

### 3.3 扫码弹窗
- 顶部标题「扫描标签 / 二维码」
- 中间：模拟扫描框（四角 + 扫描线动画 + 📷）
- 底部：MAC 地址手动输入框（placeholder：`输入标签 MAC，如 8C:CE:4E:...`）
- 操作：确认 / 取消
- 扫码成功后 → 跳转对应绑定/详情页

## 4. 数据来源与字段

### 4.1 空间信息
| 字段 | 示例 | 来源 |
|------|------|------|
| 空间ID | `space_001` | 账号-空间绑定 |
| 空间名 | XX 连锁 · 一号店 | 空间表 |
| 网关数 | 3 | 统计 |
| ESL 数 | 11 | 统计 |
| LCD 数 | 5 | 统计 |

### 4.2 设备概览统计
| 字段 | 说明 |
|------|------|
| 网关在线/离线 | 按网关在线状态计数 |
| ESL 在线/离线 | 按 ESL 心跳状态计数 |
| LCD 在线/离线 | 按 LCD 心跳状态计数 |

> 在线 = 设备最近心跳时间在阈值内；离线 = 超过阈值。告警 = 离线或电量低。

### 4.3 待办提示
- 由「ESL 离线数 + LCD 离线数（+ 待配网数）」计算。
- **无异常时该条隐藏**（前端条件渲染）。

## 6. 状态与视觉规范

| 状态 | 颜色 |
|------|------|
| 主色 / 主按钮 | 渐变 #5b7cfa → #6a5bfa |
| 成功 / 在线 | #2ec47b |
| 告警 / 离线 | #e6a23c |

| 分隔线 | #eef1f8 |

### 交互反馈
- 所有可点击元素：`:active` 时轻微缩放（0.97~0.98）。
- 主按钮：按压缩放 0.97，带投影。

## 7. 需要开发确认/注意的点

1. **「绑定标签」与「LCD绑定」的扫码流程是否共用同一弹窗**，还是各自独立（绑定类型区分）。
2. 设备概览三列是跳**同一列表页（按类型过滤）** 还是 **三个独立列表页**。
3. 待办提示条的判定阈值（离线多久算"待处理"）需要后端定义。
4. 更多工具（解绑/NFC/点灯）当前原型为占位，具体流程待补充。
5. 空间切换后各数据源的刷新时机与接口。
