# 多屏投放功能 · 详细 PRD

> 文档版本：v1.0　适用页面：多屏投放（列表页 + 新建任务向导）
> 面向对象：产品、开发、UI、测试
> 关联原型：`lcd-wall.html`
> 概述：描述多屏投放功能（LCD 大屏拼接 / 同步播放）的完整需求，含页面结构、状态模型、交互逻辑、校验规则。

---

## 1. 产品概述

### 1.1 功能定位
把多台 **LCD 显示屏**（已接入平台、同型号同分辨率）组织成一个投放任务，统一播放视频，支持**拼接播放**与**同步播放**两种模式。

### 1.2 核心价值
让用户通过简单配置，把多台 LCD 屏组织成统一展示单元，播放一个视频，降低逐台操作成本。

### 1.3 约束
- 一个任务二选一：拼接 或 同步播放。
- 组内设备必须**同型号、同分辨率**。
- 任务个数不限。

---

## 2. 任务状态模型（核心）

### 2.1 状态流转
```
编辑中 ──保存下发──→ 待播放 ──设备响应──→ 播放中
  │  ↑                    │                │
  │  │       播放失败 ←────┘                │
  └─删除/重新编辑         结束              │
                           │                │
                           ↓                │
                         任务移除（设备解放）◄┘
```

### 2.2 状态定义与操作矩阵

| 状态 | 含义 | 徽章色 | 可操作 | 说明 |
|------|------|--------|--------|------|
| **编辑中** | 建任务，未播放，可暂存 | 橙 | 编辑 / 删除 | 设备未开始播放，可改表单、删表单 |
| **待播放** | 已下发，设备异步处理中 | 蓝 | **仅结束** | 不能编辑、不能删除，只能结束（释放设备）|
| **播放中** | 设备播放成功 | 绿 | **仅结束** | 随时可结束（释放设备）|
| **播放失败** | 播放出错 | 红 | 编辑 / 删除 | 可重新编辑或删表单，不能直接结束 |

### 2.3 关键概念：删除 vs 结束

| 操作 | 对象 | 效果 | 适用状态 |
|------|------|------|---------|
| **删除** | 任务表单（数据） | 删除任务表单，设备未真正播放 | 编辑中、播放失败 |
| **结束** | 设备播放 | 结束设备播放，设备从分组解放，任务移除 | 待播放、播放中 |

> **结束** = 释放设备 + 删除任务数据；**删除** = 仅删除未播放的任务表单。

### 3.2 任务卡片字段
| 区域 | 内容 |
|------|------|
| 缩略图区 | 占位 icon + 状态徽章（左上角） |
| 标题 | 任务名称 |
| 字段行 | 设备（N 台 + 布局）、播放模式、视频名称、设备型号 |
| 操作按钮 | 按状态矩阵显示 |

### 3.3 编辑态卡片
- 蓝色描边 + 字段行蓝底高亮。
- 仅「编辑中」状态显示编辑态样式。

### 3.4 操作交互
| 操作 | 交互 |
|------|------|
| 搜索 | 按任务名称实时过滤 |
| 新建任务 | 进入 5 步创建向导 |
| 编辑 | 进入向导，回填该任务数据 |
| 删除 | 二次确认 → 移除任务（编辑中/播放失败）|
| 结束 | 二次确认 → 结束播放、解放设备、移除任务（待播放/播放中）|

## 4. 新建任务向导（5 步）

### 4.1 步骤概览
```
1 基本信息 → 2 播放模式 → 3 选择设备 → 4 编排布局 → 5 上传视频
```

### 4.2 步骤 1：基本信息
- **输入框**：分组名称（必填）。
- **底部按钮**：上一步 / 保存 / 下一步。
- **校验**：名称为空时提示「请填写分组名称」并阻止下一步。

### 4.3 步骤 2：播放模式
- **两张卡片**：拼接播放 / 同步播放。
- **拼接播放**：N 台设备拼成一个大画面，每台显示视频的一部分。
- **同步播放**：N 台设备各自完整播放同一视频。
- **交互**：点击卡片选中（蓝色描边），二选一，未选时点下一步校验。

### 4.4 步骤 3：选择设备
- **顶部工具栏**：尺寸下拉（10.1/13.3/21.5/全部）+ 搜索 MAC。
- **右侧计数**：已选 N 台。
- **设备表格列**：勾选 / 设备名称 / 设备尺寸 / 分辨率 / 状态（绿=在线，灰=离线）。
- **同型号同分辨率校验**：混入不同型号时顶部红色警告提示。
- **分页器**：页码 + 每页条数 + 跳页。

### 4.5 步骤 4：编排布局（仅拼接模式）
- **行数 / 列数输入**：手动输入（≤ 6×6）。
- **实时显示**：共 N 台设备（行×列）。
- **网格预览**：按行列生成白底空格。
- **校验**：行×列 = 已选设备数；质数设备数允许单行/单列排开。
- **同步模式**：跳过此步。

### 4.6 步骤 5：上传视频
- **上传区**：点击上传（淡蓝底 + icon 占位）。
- **提示文案**：「支持 MP4，建议视频分辨率与拼接墙总分辨率一致」。
- **上传成功**：展示视频名称 / 时长 / 分辨率 / 大小。
- **提交按钮**：「播放」（最后一步），点击开始循环播放。

---

## 5. 校验规则

| 项 | 规则 |
|----|------|
| 分组名称 | 必填，1~50 字符 |
| 播放模式 | 二选一，必选 |
| 设备数量 | ≥1；拼接模式需 = 行×列 |
| 设备型号 | 同型号同分辨率，混选触发警告 |
| 视频 | 必传；格式 MP4 |
| 视频分辨率 | 建议与拼接墙总分辨率一致 |
| 拼接行列 | ≤ 6×6 |

---

## 6. 边界与异常

| 场景 | 处理 |
|------|------|
| 设备全部离线 | 选择时提示，可勾选但建议优先在线设备 |
| 设备数量 ≠ 行列数 | 阻止下一步并提示 |
| 视频未上传 | 阻止「播放」并提示 |
| 播放失败 | 任务进入「播放失败」，可重新编辑/删除 |
| 待播放/播放中结束 | 二次确认，结束播放释放设备 |
