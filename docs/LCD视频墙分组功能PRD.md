# LCD 大屏拼接视频墙 · 分组功能 PRD

> 文档版本：v1.0　适用模块：设备管理平台 →「视频分组」
> 面向对象：产品、开发、UI、测试
> 业务背景：将已接入平台的 LCD 显示屏分组，组内 N 台设备拼成一个「大视频墙」，每台设备显示上传视频的对应部分，设置后自动循环播放。

---

## 1. 功能概述

### 1.1 核心定义
- **设备**：LCD 显示屏（已添加到平台）。
- **分组**：把多台 LCD 屏归入一个分组，分组个数不限。
- **视频墙**：组内 N 台设备拼成一个完整大屏，每台设备播放**同一视频的对应区域**（分割拼接）。
- **视频来源**：仅支持用户手动上传。
- **播放模式**：设置完成后，组内设备**自动循环播放**该视频。

### 1.2 核心价值
让用户通过简单配置，把多台 LCD 屏组成一个超大展示画面，统一播放一个宣传/展示视频，无需逐台操作。

---

## 2. 功能范围

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 分组管理 | 创建 / 编辑 / 删除分组 | P0 |
| 设备编排 | 选择设备、设定布局（行列）、调整顺序 | P0 |
| 视频管理 | 上传视频、查看视频信息 | P0 |
| 联播下发 | 配置完成后下发播放、自动循环 | P0 |

---

## 3. 核心业务流程

```
创建分组
  → 填写分组名称
  → 选择设备（从平台 LCD 设备列表勾选，可多选）
  → 编排布局（选择 行数 × 列数，设备自动填入）
  → 调整设备顺序（按列/行排列）
  → 上传视频
  → 预览视频墙效果
  → 保存并下发
  → 组内设备自动循环播放视频
```

## 4. 页面与交互设计

### 4.1 分组列表页

```
┌────────────────────────────────────────────┐
│ 视频分组                    [+ 新建分组]      │
├────────────────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐ ┌──────────┐     │
│ │ 大厅展示墙 │ │ 广告位拼接 │ │ 会议室大屏 │     │
│ │ 6 台设备  │ │ 4 台设备  │ │ 9 台设备  │     │
│ │ 播放中    │ │ 已暂停    │ │ 未配置    │     │
│ │ [播放]    │ │ [编辑]    │ │ [编辑]    │     │
│ └──────────┘ └──────────┘ └──────────┘     │
└────────────────────────────────────────────┘
```

**交互**：
- 顶部「+ 新建分组」入口。
- 分组卡片显示：名称、设备数量、播放状态、缩略图。
- 操作：播放/暂停、编辑、删除。

### 4.2 新建/编辑分组（多步骤）

**步骤 1：基本信息**
- 分组名称（必填，如「大厅展示墙」）。

**步骤 2：选择设备**
- 从平台 LCD 设备列表勾选（可多选、可搜索）。
- 显示已选设备数。

**步骤 3：编排布局**
- 选择 **行数 × 列数**（如 2×3 = 6 台）。
- 设备按顺序自动填入网格。
- 支持**调整设备顺序**（拖动或上移/下移）。
- 实时预览网格布局。

**步骤 4：上传视频**
- 点击上传视频（仅手动上传）。
- 显示视频信息：名称、时长、分辨率、大小。
- 校验：格式、分辨率需与设备匹配。

**步骤 5：预览确认**
- 预览视频墙效果（模拟 N 台设备拼接画面）。
- 确认后保存。

### 4.3 播放控制
- 保存后自动下发播放。
- 组内所有设备自动循环播放视频。
- 可远程播放/暂停/停止。

## 5. 布局与排列逻辑（核心）

### 5.1 布局模式
采用 **网格布局（行×列）**，这是拼接屏最常用的模式。

| 布局 | 示例 | 适用 |
|------|------|------|
| 单行/单列 | 1×N / N×1 | 条幅、长屏 |
| 标准网格 | 2×2、2×3、3×3 | 常规拼接墙 |
| 自定义行列 | 任意 行×列 | 灵活拼接 |

### 5.2 设备填充规则
- 用户设定 `行数 × 列数`，则分组设备数 = 行 × 列。
- 设备按**选择顺序**从左到右、从上到下填入网格。
- 支持调整顺序（拖动重排）。

### 5.3 视频切分逻辑
- 上传视频后，系统按 **列数** 等分为 N 块（列切分）。
- 每台设备播放对应列的**垂直切片**。
- 或按完整网格切分为 行×列 块，每台设备播放对应区域。

> 注：具体切分方式（按列 vs 按行列）需与播放器实现确认，建议默认**按列纵向切分**。

## 6. 数据模型

```sql
-- 分组表
CREATE TABLE video_group (
  id          INT PRIMARY KEY,
  name        VARCHAR(100) NOT NULL,      -- 分组名称
  rows        INT NOT NULL,               -- 行数
  cols        INT NOT NULL,               -- 列数
  video_id    INT,                        -- 关联视频
  status      TINYINT,                    -- 0未配置 1播放中 2已暂停
  created_at  DATETIME
);

-- 分组-设备关联表（含排列顺序）
CREATE TABLE video_group_device (
  id          INT PRIMARY KEY,
  group_id    INT NOT NULL,
  device_id   INT NOT NULL,
  col_index   INT NOT NULL,               -- 在网格中的列
  row_index   INT NOT NULL,               -- 在网格中的行
  sort_order  INT NOT NULL                -- 排列顺序
);

-- 视频表
CREATE TABLE video (
  id          INT PRIMARY KEY,
  group_id    INT,
  name        VARCHAR(100),
  file_url    VARCHAR(500),
  duration    INT,                        -- 秒
  width       INT,
  height      INT,
  size        BIGINT,                     -- 字节
  created_at  DATETIME
);
```

## 7. 校验规则

| 项 | 规则 |
|----|------|
| 分组名称 | 必填，1~50 字符 |
| 设备数量 | 必须 = 行数 × 列数 |
| 视频格式 | MP4 等常见格式，需转码支持 |
| 视频分辨率 | 需与拼接墙总分辨率匹配或提示 |
| 视频大小 | 建议限制（如 ≤ 500MB） |
| 分组个数 | 不限制 |

---

## 8. 异常与边界

| 场景 | 处理 |
|------|------|
| 设备离线 | 提示该设备离线，可能无法正常播放 |
| 设备数 ≠ 行列数 | 禁止保存，提示补齐设备或调整行列 |
| 视频上传失败 | 提示重试，保留已配置信息 |
| 视频分辨率不匹配 | 提示可能拉伸/黑边 |
| 播放中设备掉线 | 该区域黑屏，其他区域正常，提示排查 |
| 删除分组 | 二次确认，组内设备恢复独立 |

## 9. 待确认事项

1. 视频切分方式：**按列纵向切分** 还是 **按 行×列 网格切分**？
2. 视频分辨率与拼接墙总分辨率的匹配策略（自动缩放 / 提示）。
3. 设备是否必须**同型号/同分辨率**，还是支持混排？
4. 播放是否需要**远程控制**（播放/暂停/切视频），还是仅自动循环。
5. 上传视频的格式/大小/时长限制。
6. 是否需要**视频墙效果预览**（浏览器端模拟拼接）。
