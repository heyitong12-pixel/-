# 设备刷图 · 流程图

> 文档版本：v1.0　适用模块：设备列表 → 刷图
> 面向对象：开发、UI、测试
> 文档说明：描述用户从「设备列表」点击设备到完成刷图的完整流程，重点说明**在线/离线状态**与**固件版本（BLE/MIX）**的分支处理逻辑。

---

## 1. 流程概述

用户从「设备列表」点击某台设备后，系统根据**设备在线状态**和**固件版本**决定后续路径：

| 核心判定 | 说明 |
|---------|------|
| **第一层：设备在线状态** | 在线 → 直接刷图；离线 → 需进一步判断固件 |
| **第二层：固件版本（仅离线时）** | BLE → 手机蓝牙刷图；MIX → 提示需在线 |

## 3. 分支路径详细说明

### 分支 A：设备在线

| 步骤 | 动作 | 说明 |
|------|------|------|
| 1 | 设备列表点击设备 | 进入「绑定详情页」 |
| 2 | 绑定详情页 | 展示设备信息、屏幕预览、状态 |
| 3 | 正常刷图 | 通过网关/服务器下发内容到设备 |

**特点**：设备在线，走服务器下发通道，无需额外判断固件。

---

### 分支 B：设备离线 + BLE 固件

| 步骤 | 动作 | 说明 |
|------|------|------|
| 1 | 设备列表点击设备 | 检测到设备离线 |
| 2 | 扫描该标签 | 通过扫码 / NFC 识别设备，获取固件版本 |
| 3 | 判断固件 = BLE | 低功耗蓝牙版本 |
| 4 | 进入「绑定详情页」 | 展示设备信息 |
| 5 | 执行「手机蓝牙刷图」 | 通过手机 BLE 直连设备，离线也可刷图 |

**特点**：BLE 固件支持手机蓝牙直连，设备离线时仍可完成刷图。

**前置条件**：
- 手机需开启蓝牙。
- 设备在手机蓝牙可连接范围内（通常 10~30 米）。

---

### 分支 C：设备离线 + MIX 固件

| 步骤 | 动作 | 说明 |
|------|------|------|
| 1 | 设备列表点击设备 | 检测到设备离线 |
| 2 | 弹窗内扫描该标签 | 获取固件版本 |
| 3 | 判断固件 = MIX | 混合固件，不支持蓝牙直连 |
| 4 | **提示用户** | 告知「该设备为 MIX 固件，不支持手机蓝牙刷图，必须使用网关刷图」 |
| 5 | 引导操作 | 引导用户通过网关刷图（需先让设备上线） |

**特点**：MIX 固件**不支持手机蓝牙刷图**，**必须通过网关**进行刷图。

**提示文案建议**：
> 「该设备为 MIX 固件，不支持手机蓝牙刷图，必须使用网关进行刷图」

---

## 4. 关键判定规则

### 4.1 第一层：设备在线状态
- **判定依据**：设备最近心跳时间（在线阈值，如 5 分钟内有心跳 = 在线）。
- **数据来源**：设备在线状态由后端接口实时返回。

### 4.2 第二层：固件版本（仅离线时判定）
- **BLE 固件**：支持蓝牙低功耗直连 → 可离线刷图。
- **MIX 固件**：不支持蓝牙直连 → 必须在线刷图。

### 4.3 扫描获取固件（弹窗内扫描）
- 离线设备在列表右侧有「📱 扫描刷图」按钮。
- 点击按钮 → **在当前页面弹出扫描弹窗**（不跳转页面）。
- 扫描成功 → 在弹窗内直接展示固件版本（BLE / MIX）。
- 扫描失败 → 弹窗内提示「未能识别设备，请确认二维码/标签」。

**交互要点**：
- 弹窗内完成「扫描 → 判断固件 → 展示结果」全流程。
- BLE 结果：弹窗内提供「进入蓝牙刷图」按钮。
- MIX 结果：弹窗内提示「必须使用网关刷图」。

---

## 5. 异常与边界

| 场景 | 处理 |
|------|------|
| 设备在线 | 直接刷图，无需判断固件 |
| 设备离线 + BLE | 进绑定详情页，手机蓝牙刷图 |
| 设备离线 + MIX | 提示需在线，引导设备上线 |
| 扫描失败（离线） | 提示「未能识别设备」 |
| 蓝牙未开启（BLE 离线刷图） | 提示开启手机蓝牙 |
| 蓝牙连接失败（BLE） | 提示「连接失败，请靠近设备重试」 |

## 6. 界面与提示汇总

| 场景 | 界面/提示 |
|------|----------|
| 设备在线 → 进入详情 | 绑定详情页（正常展示，右侧箭头） |
| 设备离线 → 扫描 | 列表右侧「📱 扫描刷图」按钮，点击弹扫描弹窗 |
| 扫描中 | 弹窗内显示扫描框 + 扫描线动画 |
| 离线 + BLE → 刷图 | 弹窗内展示「BLE 固件」+「进入蓝牙刷图」按钮 |
| 离线 + MIX → 提示 | 弹窗内提示「MIX 固件，必须使用网关刷图」 |
| 扫描失败 | 弹窗内提示「未能识别设备，请确认二维码/标签」 |

## 7. 待确认事项

1. 「在线」的判定阈值（多少分钟无心跳算离线）。
2. BLE 刷图时，手机与设备的蓝牙连接流程（是否需要配对）。
3. 扫描获取固件的具体方式（扫码 / NFC / 手动输入 MAC）。
4. MIX 固件提示后，是否需要提供「重新检测」按钮。
5. 设备离线时的固件信息是否在设备列表中已缓存，还是必须扫码获取。
