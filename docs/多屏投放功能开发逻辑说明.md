# 多屏投放功能 · 开发逻辑说明

> 版本：v1.0　面向对象：开发
> 概述：本文档整理「多屏投放」（LCD 大屏拼接/同步播放）功能的核心业务逻辑，用产品经理视角说明规则，便于开发理解与实现。

---

## 1. 功能定义

把多台 **LCD 显示屏**（已接入平台、**同型号同分辨率**）组织成一个分组，统一投放视频，支持两种播放模式：

| 模式 | 说明 |
|------|------|
| **拼接播放** | N 台设备拼成一个完整画面，每台显示视频的对应区域（视频被切分） |
| **同步播放** | 每台设备完整播放同一个视频，各自独立显示 |

**约束**：一个分组二选一（要么拼接、要么同步）；分组个数不限。

---

## 2. 关键业务规则

### 2.1 设备约束
- 组内设备必须**同型号、同分辨率**。
- 选择设备时校验，混入不同型号/分辨率需提示并阻止。

### 2.2 设备上限
- 单个分组设置**最大行列数**（建议 `行 ≤ 6`、`列 ≤ 6`，即最多 36 台，具体值按拼接引擎能力定）。
- 该上限是**固定技术上限**，与视频无关（因为布局步骤在视频上传之前）。
- 超过上限时禁止输入并提示。

### 2.3 排列必须是标准长方形
- 拼接模式要求排列为**完整长方形**（每行设备数一致，不能异型）。
- **合法排列**：`行数 × 列数 = 设备总数`。
- **质数设备数**（如 5、7、11）：无法构成标准 m×n（m,n>1），**允许单行排开（1×n）或单列排开（n×1）**。

---

## 3. 拼接布局的默认排列算法

### 3.1 目的
用户选完设备进入「编排布局」时，若手动不设置行列，系统应**根据设备总数自动推导一个最接近正方形的默认排列**，避免空白或错误。

### 3.2 规则
- 找一对 `行 × 列 = 设备数`，且**行、列最接近**（排列最接近正方形）。
- 设备数为质数时，用**单行**（1×设备数）。

### 3.3 算法（等价伪代码）
```
输入：设备数 n
输出：{rows, cols}

若 n <= 1：返回 {1, 1}

从 rows = ⌊√n⌋ 开始，向下遍历：
    若 n % rows == 0：
        返回 { rows, n / rows }

遍历完仍未找到（质数）：返回 { 1, n }
```

### 3.4 示例
| 设备数 n | √n | 找到的因子 | 默认排列 |
|---------|-----|-----------|---------|
| 4 | 2 | 2 | 2×2 |
| 6 | 2 | 2 | 2×3 |
| 8 | 2 | 2 | 2×4 |
| 9 | 3 | 3 | 3×3 |
| 12 | 3 | 3 | 3×4 |
| 7（质数） | 2 | 无→单行 | 1×7 |

### 3.5 实现注意
- 用**整数平方根**计算（Python 用 `math.isqrt`，Java 用 `(int)Math.sqrt`），避免浮点误差。
- 复杂度 O(√n)，性能无问题。
- 前端拿到 `{rows, cols}` 后填入行列输入框并渲染。

## 4. 布局数量校验规则

用户手动调整行列时，实时校验，给出明确提示：

| 场景 | 提示 |
|------|------|
| 布局区域数 **>** 已选设备数 | 「布局中设备数量（X）大于已选设备数（Y），请减少行数/列数或补充设备」 |
| 布局区域数 **<** 已选设备数 | 「布局中设备数量（X）小于已选设备数（Y），请增加行数/列数或减少设备」 |
| 区域数=设备数但无法整除（质数） | 「设备数量与布局不匹配，可设 1 行或 1 列排开」 |
| 合法（标准长方形/单行/单列） | 允许继续 |

**校验核心**：`行数 × 列数 === 设备数` 且 `设备数 % 行数 === 0`（每行设备数一致）；或 `行=1` 或 `列=1`。

## 5. 新建分组流程（交互步骤）

```
1. 基本信息   → 填写分组名称（必填）
2. 播放模式   → 选择「拼接播放」或「同步播放」（二选一）
3. 选择设备   → 从 LCD 设备列表勾选（同型号同分辨率校验）
4. 编排布局   → 仅拼接模式：自动推导默认排列 + 手动调整 + 长方形校验
             → 同步模式：跳过布局，每台播放完整视频
5. 上传视频   → 手动上传（格式 MP4，建议分辨率与设备匹配）
6. 保存播放   → 下发，组内设备自动循环播放
```

## 6. 待开发确认

1. **设备上限值**：拼接引擎实际支持的最大行列（当前建议 6×6）。
2. **视频切分方式**：拼接模式下视频如何切分（建议按「列」纵向切分为每台对应区域）。
3. 视频分辨率与拼接总分辨率的匹配策略（自动缩放 / 提示）。
